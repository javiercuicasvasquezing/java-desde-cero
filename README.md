## Método

Cada problema se resuelve con los mismos pasos, aunque parezca fácil:

1. Problema con mis palabras
2. Análisis
3. Entradas y salidas, con su tipo de dato
4. Ejemplo resuelto a mano, con números concretos
5. Proceso y algoritmo
6. Pseudocódigo
7. Prueba de escritorio con tabla de variables
8. Predicción exacta de la salida
9. Ejecución en PSeInt (etapa 1) o Java (desde la etapa 2)
10. Commit

## Cómo ejecutar

- **Etapa 1:** abrir el archivo `.psc` en PSeInt y ejecutarlo.
- **Java:** desde la carpeta del ejercicio:

```bash
javac Archivo.java
java Archivo
```
